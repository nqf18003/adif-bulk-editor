# ADIF一括編集ツール（ADIF Bulk Editor）

**▶ 使う（公開ページ）: https://nqf18003.github.io/adif-bulk-editor/**

> **現在テスト中です。** 保存したファイルは、アップロードする前に中身を確かめてください（元のファイルは書き換えません）。

HAMRS などのログソフトで記録した SOTA/POTA 運用ログ（ADIF）を、1画面で直して SOTA・POTA・eQSL・LoTW 用のファイルにするツールです。

## 使えるもの
- パソコンの Chrome・Edge（保存先のフォルダを選んで、まとめて保存できます）
- ほかのブラウザーでは、保存のときにファイルを 1 つずつダウンロードします。

## 使い方
1. 公開ページを Chrome（または Edge）で開きます。
2. 「ADIFを開く」を押すか、ADIF ファイルを画面にドラッグ＆ドロップします。
3. 共通項目（POTA公園など）を確かめて、足りないものを入れます。QSL MSG は、横の「自動で作る」にチェックを入れると自動で作られます（はじめはチェック無し。選んだものはブラウザーが覚えます）。
4. 「ADIFを保存」を押し、保存先のフォルダを選びます。作られるファイルの一覧を確かめて（ファイル名はここで直せます）「保存する」を押します。

- インターネットにつながらないパソコンで使うときは、このリポジトリの `index.html` をダウンロードし、ダブルクリックして Chrome（または Edge）で開きます。

## できること
- 開くときに、項目名 OPERATOR → STATION_CALLSIGN への変更（STATION_CALLSIGN がすでにあれば変えず、違うコールサインの OPERATOR は残します）・QSO_DATE_OFF の削除・項目の整列を、するかどうかチェックボックスで選べます
  （はじめは3つともしない。選んだものは、ブラウザーが覚えておきます）。
  整列の並び順は、その下の欄で好きな順に変えられます（項目名をカンマか空白で区切って書きます。書いていない項目は後ろに元の順で並びます。「初めの順に戻す」で元の並び順に戻ります）。HAMRS の ADIF を SOTA・POTA 用に直すときは、3つともチェックを入れ、QSL MSG の「自動で作る」にもチェックを入れます。
- MY_SIG・MY_SIG_INFO・QSLMSG を全QSOに入れます。
- 保存するファイルは、UTC日付ごと・公園ごと（2fer・3fer の公園2・3は `sub` 付きのファイル）に分けます。ファイル名は `日付-SOTA-山頂-POTA-公園-JCC.adi` の形です（保存の前に直せます）。
- QSL MSG は「ひな形」の欄で文の形を変えられます（`{SOTA}` `{POTA}` `{JCC}` `{MYCALL}` `{GRID}` が値に置き換わります）。
- チェックボックスや選んだもの、ひな形は、ブラウザーが覚えておきます。
- ファイル名に `jcc-1001` や `jcg-13001a` のように JCC/JCG が入っていれば、JCC/JCG の欄に読み取ります。
- 文字コードは UTF-8 と Shift_JIS（ターボ HAMLOG など）を自動で見分けて読みます（開く画面で選び直せます）。保存は UTF-8 です。
- 開いた元のファイルは書き換えません（読み取るだけです）。保存では新しいファイルを作ります。元のファイルと同じ名前のファイルが保存先にあるときは、上書きしないよう別の名前にしてもらいます。
- 移動運用ログの 2fer・3fer（公園が `JP-0001,JP-0002` のようにつながった ADIF）は、開いたときに公園 1〜3 に分けます。
- 表のセルを直接書き換えたり、行を追加・削除したりできます。
- 表のすぐ下のつまみをドラッグすると、表の高さを変えられます（ダブルクリックで元の高さ。高さはブラウザーが覚えます）。

## アップロード先
- POTA: 親ファイルと sub ファイルすべて
- SOTA・eQSL・LoTW: 親ファイルだけ（`sub` で始まるファイルは上げない）

データは、あなたのパソコンの中だけで扱います（開いたファイルを直して、選んだフォルダに保存するだけ）。インターネットには何も送りません。
